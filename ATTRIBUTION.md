# Attribution & Upstream Context

This repository (`iennae/Makeblock-Libraries`) is a fork of the community [`Makeblock Drive Updated`](https://github.com/nbourre/Makeblock-Libraries) library (v3.31.0), which itself was forked from Makeblock's official [`Makeblock-official/Makeblock-Libraries`](https://github.com/Makeblock-official/Makeblock-Libraries).

The notes below are preserved from those prior upstream repositories to retain full author credit and historical context.

---

## Upstream Maintainer Note (`Makeblock Library v3.31.0 - Updated`)

> *Preserved from Nicolas Bourré / Nick B (`Makeblock Drive Updated` v3.31.0):*
>
> The original library from Makeblock is not maintained anymore. I have a fleet of Makeblock Ranger robots and I needed to fix some issues with the library. I will try to keep it up to date with the original library.
>
> Feel free to open an issue if you have any problem with the library or create a pull request if you have a fix.
